# CodeAlpha Task 3 - Banking System

## Description
A simple Banking System developed in C++ for the CodeAlpha Internship.

## Features
- Create and manage accounts
- Deposit money
- Withdraw money
- Transfer funds
- View account information
- Store and view transaction history
- Display customer information

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- Visual Studio Code

## Classes
- Customer
- Account
- Transaction

## How to Run
Compile the program using:

g++ main.cpp -o task3

Then run:

.\task3
